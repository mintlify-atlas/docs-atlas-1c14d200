Mixly is an open-source, block-based programming environment designed for beginners, educators, and hardware enthusiasts. Build programs by dragging and connecting visual blocks — Mixly automatically generates the underlying Arduino C++ or Python code and uploads it directly to your board via USB or Wi-Fi.

## How it works

<Steps>
  <Step title="Choose a board">
    Select your hardware from the board selector in the navigation bar. Mixly loads the matching toolbox categories, pin definitions, and code generator for that board.
  </Step>
  <Step title="Build your program">
    Drag blocks from the left toolbox into the workspace. Switch to the split Mix view to see the generated code update live alongside your blocks.
  </Step>
  <Step title="Connect via USB or serial">
    Plug in your board. Mixly detects available serial ports automatically (desktop) or prompts you to grant WebSerial access (browser).
  </Step>
  <Step title="Upload or run">
    Click the upload button. Mixly compiles (Arduino) or transfers (MicroPython/Python) your program to the board and streams the output to the serial monitor.
  </Step>
</Steps>

<Note>
  Mixly runs on Windows, macOS, and Linux as an Electron desktop app, and in any modern Chromium-based browser using WebSerial for hardware communication.
</Note>
