Mixly is a graphical programming environment built on top of Google Blockly, designed for beginners and hardware enthusiasts who want to write firmware for microcontrollers without hand-coding every line. You drag and snap blocks together on a canvas, and Mixly continuously generates the corresponding C/C++ or Python source code in a side panel — no compile step needed to see what your program looks like. When you are ready, you click Upload and Mixly drives the toolchain for you.

## Deployment modes

Mixly 3.0 ships in two forms that share the same codebase and block libraries.

<CardGroup cols={2}>
  <Card title="Electron Desktop App" icon="desktop">
    A self-contained Electron application that bundles Node.js, the Arduino CLI, and Python runtimes. Supports all boards including Arduino AVR, ESP32, and ESP8266. Serial port access is handled natively through the OS, and USB hot-plug events are detected automatically via `usb-detection`.
  </Card>
  <Card title="Web Browser (Chromium)" icon="globe">
    Runs entirely in a modern Chromium browser using the WebSerial API. No installation is required — navigate to the local Express static server (HTTP on port 7000, HTTPS on port 8000) or a hosted instance and start programming. Some boards are limited to web-compiler or WebSocket upload modes in this environment.
  </Card>
</CardGroup>

## Key features

<CardGroup cols={3}>
  <Card title="Live Code Preview" icon="eye">
    The code panel updates in real time as you drag and configure blocks. C/C++ and Python output is syntax-highlighted using the Ace editor.
  </Card>
  <Card title="Light & Dark Themes" icon="moon">
    Switch between a light theme (Blockly Classic + Xcode editor) and a dark theme (Blockly Dark + Dracula editor). The theme also follows the OS `prefers-color-scheme` media query automatically.
  </Card>
  <Card title="Multi-language UI" icon="language">
    The interface ships in Simplified Chinese (`zh-hans`), Traditional Chinese (`zh-hant`), and English (`en`). The language is auto-detected from `navigator.language` but can be changed manually in settings.
  </Card>
  <Card title="Block Toolbox Search" icon="magnifying-glass">
    A built-in toolbox searcher lets you find any block by keyword without scrolling through category trees.
  </Card>
  <Card title="Serial Monitor & Plotter" icon="chart-line">
    An integrated serial output panel and chart view lets you read sensor data directly inside the IDE after uploading — no separate terminal needed.
  </Card>
  <Card title="Library & Board Manager" icon="box-open">
    Download and manage Arduino libraries and third-party board packages from within the IDE. Board definitions are fetched from the Mixly cloud board registry.
  </Card>
</CardGroup>

## Language support

| UI Language | Code (`language` value) | Auto-detected from |
|---|---|---|
| English | `en` | Any locale not matching Chinese |
| Simplified Chinese | `zh-hans` | `zh-CN` |
| Traditional Chinese | `zh-hant` | `zh-HK`, `zh-SG`, `zh-TW` |

<Note>
  The default language at first launch is Simplified Chinese (`zh-hans`). You can change it in the user settings panel inside the IDE.
</Note>
